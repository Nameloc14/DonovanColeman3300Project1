Known bugs / missing functionality:
No known bugs. All required functionality has been implemented.

Design notes:
If the inventory contains two cars with the same make AND model, purchasing
one sells the first matching car in the inventory. This follows the
required CarLot.PurchaseCar(make, model) signature, which identifies a
car by make and model only.

Shopper has one extra read-only property, PurchasedCars, so the UI can
display the shopper's purchased cars (extra credit 2) without being able
to modify the shopper's private list.
